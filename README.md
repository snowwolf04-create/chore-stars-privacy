# Chore Stars — privacy policy

This repository exists for one reason: to host the public privacy policy for the
**Chore Stars** Android app at a stable web address, which the Google Play
Console requires.

The live page is served by GitHub Pages from `index.html` in this repository.

The app itself is developed in a separate, private repository. Nothing here is
part of the app's source code.

## Keeping it in sync

The master copy of this page lives at `privacy/index.html` in the app
repository. If the policy changes there, copy the file across and commit it here
too, so the published page and the app never disagree.
